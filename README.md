#password hashing tool
A simple python project for password hashing and verification.

#About 
This project demonstrates how password can be converted into hash by using SHA-256 and how password can be verified by compering its hash with stored hash.
The project was created as a begginer cybersecurity project while learning python.

#Features
Convert pass with SHA-256 hashes
verify pass against a stored pass 
Simple command line menu 
continues menu using while True
Built with python standard libraries 


#Technologies
Python3
Hashlib
SHA-256
